# 🏥 WellSpring Hospital Management System

A simple web-based hospital management system developed using Python Flask, HTML, CSS, JavaScript, and SQLite.

## ✨ Features

- Patient Management
- Doctor Management
- Appointment Booking
- Billing Management
- Search Records
- Responsive Design

## 🛠️ Technologies

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLite
